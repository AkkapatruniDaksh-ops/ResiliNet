# 🤝 Contributing to ResiliNet

Thank you for your interest in contributing to ResiliNet!

Contributions, bug reports, suggestions, and feature improvements are welcome.

## 🚀 How to Contribute

1. Fork the repository.
2. Clone your fork.
3. Create a new feature branch.
4. Make your changes.
5. Test your changes.
6. Commit and push your branch.
7. Open a Pull Request.

## 🌿 Branch Naming

Use descriptive branch names:

- `feature/weather-alerts`
- `feature/dashboard-improvements`
- `fix/authentication`
- `docs/readme-update`

## 🐛 Reporting Bugs

Please create a GitHub Issue and include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected behaviour.
- Actual behaviour.
- Screenshots or error messages, if applicable.

## 💡 Suggesting Features

Open an issue describing the proposed feature, its purpose, and how it could improve ResiliNet.

## 🔐 Security Issues

Do not publish passwords, API keys, OAuth secrets, or other sensitive information in issues or pull requests.

## 📜 Code of Conduct

Be respectful, constructive, and professional when participating in this project.

Thank you for helping improve ResiliNet! 🌦️
