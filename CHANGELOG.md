# 📋 Changelog

All notable changes to ResiliNet are documented in this file.

This project follows a version-based release history.

## [1.0.0] - 2026-11-12

### 🎉 Initial Public Release

- 🌤️ Weather monitoring and forecast dashboard.
- 🚨 Multi-level weather risk assessment.
- 🛰️ Interactive weather radar and maps.
- 🌊 Flood-related weather indicators.
- 🏘️ Community weather reporting.
- 🖥️ Disaster management console.
- 🔐 User authentication and account functionality.
- 📍 Location subscriptions and alert preferences.
- 📱 Configurable notification integrations.
- ☁️ Cloudflare Pages deployment with D1 database integration.
